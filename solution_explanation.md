# Solution explanation

This task is a numerical audit of an anisotropic three-dimensional Anderson-model study rather than a direct textbook calculation. The central difficulty is that the three campaigns contain both valid measurements and records that should not be treated as independent scientific evidence. The reference workflow therefore begins by separating data lineage and numerical quality from physical interpretation.

For the transfer-matrix data, every row represents one completed run summarized by its smallest positive Lyapunov exponent. Restarted checkpoints are explicitly linked to a parent run through `parent_sample_id`; they are rejected because they duplicate numerical history rather than supply a new disorder realization. Runs are also rejected if they fail the minimum block count or bar length, report QR failures, do not converge, or exceed the permitted relative Lyapunov uncertainty. For each retained run the dimensionless quasi-one-dimensional localization length is computed as Lambda_M = 1/(M gamma). Independent runs at the same anisotropy and width are then aggregated with an ordinary realization-level mean and standard error. Internal transfer blocks are not counted as separate experimental realizations.

The spectral table represents a second numerical pipeline. Each row summarizes one exact-diagonalisation realization after energy-window selection. Eigensolver residuals, orthogonality defects, converged-state counts and the presence of the corresponding twisted-boundary calculation are audited before the row can contribute. Exact compact modes have already been removed upstream from the reported dispersive-state observables; the `compact_states` field records how many were removed so that retained-state counts remain auditable. Participation statistics are aggregated in logarithmic space. Specifically, the typical second-order inverse participation ratio is obtained by exponentiating the realization-averaged log-IPR. This avoids treating a broad IPR distribution as though it were approximately Gaussian. Adjacent-gap ratios and twisted-boundary shifts are aggregated over independent realizations with realization-level standard errors.

The critical point is inferred from the transfer-matrix table because it contains the clearest sequence of system widths. Two physically plausible finite-size models are compared. The first contains only the leading relevant scaling field. The second adds a leading irrelevant correction proportional to M^{-1}. Both estimate the critical anisotropy and correlation-length exponent. Weighted nonlinear least squares is used with the independently estimated standard errors of Lambda_M. Akaike information criterion selects the model: the irrelevant correction is retained only when the improvement in fit outweighs the penalty for the extra parameter.

Uncertainty is quantified by a deterministic parametric bootstrap. Each aggregated Lambda_M value is redrawn from a normal distribution centered on the measured value with width equal to its realization-level standard error. The selected finite-size model is refitted to 200 bootstrap tables. Percentiles of the fitted critical anisotropy and correlation-length exponent define the reported 95 percent intervals.

The final phase map is constrained by the fitted critical point but is cross-checked against all diagnostics. The sampled anisotropy nearest the fitted critical value is labelled critical. Values below it are labelled localized and values above it metallic. Transfer size-flow slopes are reported as the primary evidence. Participation slopes, adjacent-gap ratios and twisted-boundary sensitivity are attached as secondary evidence because those observables exhibit stronger finite-size drift on the smaller exact-diagonalisation systems.

The verifier independently reconstructs the quality-control decisions from the raw tables, recomputes every aggregated transfer and spectral observable, checks critical-parameter plausibility and confidence-interval consistency, validates the monotonic phase ordering, and requires scientific discussion of all four diagnostics in the report. Consequently, the task cannot be passed by producing empty files, plausible-looking constants, or correct schemas without reproducing the scientific workflow.
